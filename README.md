# Ceibo Software - Landing Page

Landing page oficial de **Ceibo Software**, desarrollada con Next.js 16, React 19, Tailwind CSS y Framer Motion.

---

## 🚀 Pasos para levantar el proyecto

### 1. Requisitos previos
- **Node.js** v20 o superior
- **pnpm** (recomendado v9 o superior)

> Si no tienes `pnpm` instalado globalmente, puedes habilitarlo o instalarlo con:
> ```bash
> corepack enable
> # o mediante npm:
> npm install -g pnpm
> ```

---

### 2. Instalar dependencias
Desde la raíz del proyecto, ejecuta:

```bash
pnpm install
```

---

### 3. Iniciar el servidor de desarrollo
Para correr el proyecto en modo desarrollo con Turbopack:

```bash
pnpm dev
```

Una vez iniciado, abre [http://localhost:3000](http://localhost:3000) en tu navegador.

---

### 4. Compilar para producción
Para generar el build optimizado de producción y previsualizarlo:

```bash
# Crear la compilación de producción
pnpm build

# Iniciar el servidor con el build generado
pnpm start
```
